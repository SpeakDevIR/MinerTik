راهنمای فورک و ویرایش پروژه MinerTik
=====================================

![Keep Alive Status](https://github.com/speakdevir/MinerTik/actions/workflows/main.yml/badge.svg)

معرفی
-------
پروژه MinerTik یک صفحه وب ساده است که برای نمایش وضعیت ماینینگ یا هر محتوای دیگری طراحی شده است. این پروژه با استفاده از GitHub Actions به‌روز نگه داشته می‌شود و به راحتی قابل شخصی‌سازی است.

لینک دسترسی به نسخه‌ی زنده:
https://speakdevir.github.io/MinerTik


آموزش فورک (Fork) کردن پروژه
-------------------------------
برای شروع، ابتدا پروژه را به حساب کاربری خود در گیت‌هاب کپی (فورک) کنید:

1. به صفحه‌ی اصلی پروژه بروید:
   https://github.com/speakdevir/MinerTik

2. در بالای صفحه، دکمه‌ی Fork را کلیک کنید.

3. حساب کاربری خود را انتخاب کنید و منتظر بمانید تا فورک انجام شود.

4. حالا پروژه در ریپازیتوری شما قرار دارد و می‌توانید آن را ویرایش کنید.


ویرایش فایل index.html
------------------------
برای تغییر محتوای صفحه، فایل index.html را ویرایش کنید. این فایل شامل ساختار اصلی صفحه است.

مراحل ویرایش:
1. در ریپازیتوری فورک‌شده‌ی خود، روی فایل index.html کلیک کنید.

2. روی آیکون مداد (ویرایش) در بالای صفحه کلیک کنید.

3. تغییرات مورد نظر خود را اعمال کنید. برای مثال:
   - تغییر عنوان صفحه: خط <title> را ویرایش کنید.
   - تغییر متن اصلی: بخش‌های <h1>، <p> و غیره را مطابق نیاز خود تغییر دهید.
   - تغییر لینک‌ها: آدرس‌های موجود در تگ‌های <a> را به دلخواه عوض کنید.
   - تغییر استایل: می‌توانید استایل‌های درون تگ <style> را دستکاری کنید.

4. پس از اتمام ویرایش، در پایین صفحه، پیام commit را وارد کنید (مثلاً "Update index.html") و دکمه‌ی Commit changes را بزنید.

5. بعد از چند ثانیه، سایت شما در آدرس زیر به‌روز می‌شود:
   https://[your-username].github.io/MinerTik
   (به جای [your-username] نام کاربری خود را قرار دهید.)


توضیح نشانگر وضعیت (Badge)
-----------------------------
نشانگر Keep Alive Status در بالای این فایل، وضعیت آخرین اجرای اکشن گیت‌هاب را نشان می‌دهد. این اکشن به گونه‌ای تنظیم شده که پروژه را همواره فعال نگه دارد و در صورت بروز مشکل، شما را مطلع می‌سازد.


نکات مهم
----------
- پس از هر ویرایش، منتظر بمانید تا GitHub Pages سایت شما را بازسازی کند (معمولاً کمتر از یک دقیقه).
- اگر تغییری در صفحه مشاهده نمی‌کنید، کش مرورگر خود را پاک کنید.
- برای بازگرداندن تغییرات، همیشه می‌توانید به نسخه‌ی قبلی در تاریخچه‌ی کامیت‌ها برگردید.


مشارکت
--------
اگر ایده یا بهبودی برای پروژه دارید، خوشحال می‌شویم که آن را با ما به اشتراک بگذارید. می‌توانید یک Pull Request ارسال کنید یا Issue جدیدی باز کنید.
